# Blog Project

## 📋 Sobre o projeto

Este projeto tem como objetivo fornecer uma API para gerenciamento de:

- Usuários
- Posts
- Comentários
- Categorias

## 🚀 Tecnologias

- Java 21
- Spring Boot 4.1.1
- Spring Web
- Spring Data JPA
- MariaDB
- Maven

## ▶️ Como executar

Clone o projeto:

```bash
git clone https://github.com/AnaGabK/blog-project.git
```

Entre na pasta:

```bash
cd blog-project
```

Execute:

```bash
./mvnw spring-boot:run
```

Ou:

```bash
mvn spring-boot:run
```
